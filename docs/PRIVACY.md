# 隐私说明

GPT 随页助手没有自己的服务器，也不包含分析统计或广告代码。它在你的 Chrome 中运行，并使用你已登录的 ChatGPT 网页账号完成回答。

## 何时读取与发送数据

扩展只在你进行下列操作时准备页面资料：

- 点击“加入当前页”：提取当前页正文，供下一次发送使用。
- 点击“总结当前页”：提取当前页正文并发送总结请求。
- 点击“校正翻译”或在明确加入 YouTube 页面后发送：读取该视频的字幕。

普通追问只发送你输入的文字，并沿用当前临时聊天；切换或新打开网页不会自动发送页面内容。

## 数据会去哪里

| 数据 | 接收方 | 原因 |
| --- | --- | --- |
| 你的问题、主动选择的网页正文、字幕、页面标题与 URL | ChatGPT | 生成回答、总结或翻译 |
| YouTube 视频 URL | DownSub | 查找并返回原始语言字幕 |
| 页面正文 | 不发送给 DownSub | 字幕以外的普通网页处理不经过 DownSub |

如果 DownSub 无法完成，扩展会尝试直接读取 YouTube 已提供的字幕轨道。字幕提取代码本身不调用语言模型；只有分析、总结、校正和翻译请求会发送给 ChatGPT。

扩展使用你自己的 ChatGPT 账号，因此账号套餐、用量、速率限制和服务条款照常适用。它不读取或保存 API Key，也没有独立的 API 凭证。

## 本机保存

- **会话存储**：当前窗口的短问题、回答、请求状态、字幕是否已提供、翻译断点等元数据。Chrome 会话存储用于侧栏重开和 Service Worker 重启恢复。
- **内存**：待发送字幕分段最多 500,000 字符。已确认发送的分段会释放；任务完成、开始新任务或侧栏页面卸载时会清理。
- **本地存储**：只持久保存侧栏正文字号。

扩展不把完整网页正文、原始字幕文件或构造后的完整提示词写入磁盘。停止回答时，已经收到的部分回答会保留在当前问答记录中。

## ChatGPT 临时聊天

扩展会检查 ChatGPT 页面确实处于临时聊天模式后才发送。根据 OpenAI 的[临时聊天说明](https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt)，临时聊天通常不显示在历史记录中，也不用于训练模型；出于安全目的，OpenAI 仍可能保留副本最多 30 天。若你主动保存临时聊天，它可能进入历史记录。临时聊天仍可能使用账号中已有的记忆来个性化回答；本扩展不会关闭或改变你的全局记忆设置。

扩展无法承诺第三方服务器即时删除数据。ChatGPT 与 DownSub 如何处理收到的数据，分别受其自身政策与服务控制。

## 权限与边界

扩展请求广泛的 HTTP/HTTPS 站点权限，是为了让你能在不同网页上手动提取正文。源码中的提取器会删除表单、输入框、可编辑区域、按钮、导航和隐藏元素，再返回主要可见文本；但网页结构复杂时仍可能包含页面中显示的其他文字。发送前请确认当前页面适合交给 ChatGPT 处理。

扩展不会绕过登录、验证码、付费墙或访问控制。它不是 OpenAI、ChatGPT、YouTube 或 DownSub 的官方产品。

## 删除数据

关闭浏览器会结束 Chrome 的会话存储生命周期；具体清理由 Chrome 管理。若要立即移除扩展保存的全部本地数据，可在 `chrome://extensions` 中移除扩展。ChatGPT 或 DownSub 已接收的数据需要按各自服务提供的账号与隐私工具处理。
