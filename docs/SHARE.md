# 分享文案

为了看网页和 YouTube 时少切换页面，我做了一个 Chrome 扩展「GPT 随页助手」，现在 MIT 开源了。

在侧边栏里总结网页、分析视频字幕、连续追问，也能逐段校正翻译日语、英语和泰语。复用自己的 ChatGPT 网页账号，无需填写 API 密钥。

这是一个 AI 辅助独立开发的 Beta 项目，安装教程、源码和工程流程图都在仓库里。欢迎试用、反馈或一起改进。

项目：https://github.com/kinniuroudong-glitch/gpt-sidebar-assistant

配图：[工程流程图](assets/workflow.png)。安装请参考 [安装手册](INSTALL.md)。
