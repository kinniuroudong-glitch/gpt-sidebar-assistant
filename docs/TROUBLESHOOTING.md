# 故障排查

先做这组通用恢复操作：在 `chrome://extensions` 找到 GPT 随页助手，点击刷新图标；刷新来源网页；关闭后重新打开侧栏；确认普通标签页中的 ChatGPT 已登录。更新代码后必须执行这些步骤，Chrome 不会自动重新加载本地扩展。

## 侧栏打不开或功能没有更新

1. 确认加载的是仓库中的 `extension/` 文件夹，该目录内应直接有 `manifest.json`。
2. 查看扩展卡片版本是否为 0.12.4。
3. 确认 Chrome 版本不低于 116，建议升级到当前稳定版。
4. 点击扩展卡片刷新图标，再刷新来源页并重开侧栏。

## 提示未登录、页面未准备好或临时模式未确认

- 在普通标签页打开 <https://chatgpt.com/> 并完成登录、验证码或账号提示。
- 不要关闭扩展创建的 ChatGPT 标签页；它是当前会话载体。
- 如果 ChatGPT 页面结构刚更新，刷新扩展后重试。扩展必须看到明确的临时聊天界面才会发送，无法确认时会停止而不是降级为普通聊天。

## 网页正文为空或无法读取

- 当前页必须是 `http://` 或 `https://` 页面。Chrome 内部页、扩展页和 ChatGPT 页不会作为来源读取。
- 在扩展详情页允许访问当前网站，然后刷新网页。
- 登录墙、跨域 iframe、Canvas 应用和大量动态渲染页面可能没有可提取的正文。
- 新打开的页面不会自动附加。请点击“＋”加入当前页，或直接点击“总结”。

## YouTube 字幕提取失败

1. 确认视频本身提供字幕，并等待播放器页面加载完成。
2. 在扩展的网站访问权限中允许 `youtube.com`、`downsub.com` 和 `subtitle.downsub.com`。
3. 刷新扩展并重试。字幕任务最长可能等待约 90 秒。
4. 如果 DownSub 暂时不可用，扩展会自动尝试 YouTube 原生字幕轨道；两者都不可用时不会发送空字幕。

扩展只选择视频原始语言字幕，并优先人工字幕。语言元数据含糊、只有翻译字幕、视频切换、字幕与原语言不符时会主动停止。日语、英语和泰语之外的原始语言目前未作为正式支持路径验证。

## 回答停住、没有实时更新或一直显示“正在回答”

- 保持扩展创建的 ChatGPT 标签页存在，并确认其中没有登录提示、服务错误或验证码。
- 可点击侧栏方形停止按钮。只有在 ChatGPT 显示真实停止控件时，扩展才会确认停止；已收到的部分回答会保留。
- 回答回传优先读取匹配当前请求的响应流，并以页面 DOM 回退。ChatGPT 协议或页面结构变化时，增量显示可能延迟到 DOM 可读。
- 重开侧栏通常会从会话状态恢复当前回答；若原临时聊天已丢失，需要重新发送。

## “继续”按钮不出现或继续后停止

“继续”只在校正翻译还有未处理段落且断点保存完成后显示。出现以下情况时会停止，以防重复或错位：

- 原视频已切换或关闭；
- 重新读取的字幕指纹与之前不同；
- 原 ChatGPT 字幕上下文已丢失；
- 模型没有返回唯一、可靠的继续位置。

当前段回答会保留。回到原视频重新点击“校正翻译”可开始新任务。

## 输入与显示问题

- `Enter` 发送，`Shift+Enter` 换行。输入法正在组合文字时不会发送。
- 顶部 `A−` / `A＋` 以 3 px 调整字号，范围是 18–54 px。
- 若旧回答缺少有序列表编号，那是旧 DOM 快照的限制；扩展不会猜测并重建已经丢失的编号。

## 报告问题

请使用 GitHub 的 Bug Report 模板，填写 Chrome、系统、扩展版本、复现步骤和实际错误文字。可以附截图，但请遮盖姓名、头像、邮箱、聊天内容、视频历史、标签页和任何私密页面信息。不要提交账号凭证、Cookie、请求头、会话令牌或完整私人字幕。
